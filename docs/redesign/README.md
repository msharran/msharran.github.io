# Website visual review

Nothing-inspired redesign of msharran.github.io. Dark first, with a saved light-theme preference. Screenshots are captured from the real Jekyll build at desktop (1440 × 1000) and mobile (390 × 844) sizes. Long-page captures can be opened at full resolution.

Start with the intro comparison, then scan the dark and light themes below. Article and profile content, code blocks, note artifacts, and existing page URLs are preserved.
